# SWE Daily — Scaffold Request

I'm building a web app called SWE Daily. Right now I only want the BOILERPLATE
and project skeleton set up. Do not implement business logic yet. Stub the
functions with docstrings and TODOs so I can fill them in myself.

## Context (so you scaffold the right shape)
A daily tech news digest for aspiring SWEs, plus a simple todo list. One cron
job per day pulls from Hacker News, RSS feeds, and Reddit, dedupes, tags by
topic, scores, picks the top ~10, runs those through the Gemini API for a
summary and a "why this matters for you" blurb, and writes that day's digest.
Users pick topics, read the digest, then see their todo list underneath it.

## Stack
- Backend: FastAPI (Python 3.11+)
- DB: Postgres (Neon), accessed with psycopg 3
- Frontend: React + Vite
- Cron: GitHub Actions workflow hitting a protected endpoint
- Deploy: backend on Render, frontend on Vercel

## Database rule (important)
I'm building this to learn SQL. No ORM, no query builder. Use psycopg with raw
SQL. Migrations are hand-written numbered .sql files. When you scaffold a query
function, leave the SQL as a TODO comment rather than writing it for me, except
where I ask below.
